# SOC Home Lab

Hands-on cybersecurity lab designed to simulate a small enterprise SOC environment and develop practical skills in SIEM monitoring, detection, threat investigation, and incident response.

## Lab Environment

| System | Purpose |
|---|---|
| Kali Linux | Security testing and attack simulation |
| DC01 | Active Directory Domain Controller |
| CLIENT01 | Windows endpoint |
| Wazuh | Endpoint monitoring and detection |
| Splunk Enterprise | SIEM and security log analysis |
